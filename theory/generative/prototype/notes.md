# Prototype

**Prototype** - порождающий паттерн: новый объект получают **копированием** существующего образца (`Clone`), а не через `New` / конструктор с нуля.

Полезно, когда создание дорогое или нужен объект "как этот, но с правками".

## Схема

```
Client
  |
  |
  |
  v
template.Clone()  ----->  копия (можно изменить поля)
```

## Когда уместно

- инициализация тяжелая (загрузка, парсинг, сеть)
- нужны варианты одного шаблона (отчет, форма, конфиг)
- тип знает, как себя копировать (в Go - метод `Clone()` у типа)

## Не путать

| | Prototype | Factory Method / Simple Factory |
|---|-----------|----------------------------------|
| Откуда объект | копия образца | создают заново |
| Типичный API | `Clone()` | `Create()` / `New()` |

| | Prototype (shallow) | Prototype (deep) |
|---|---------------------|------------------|
| Вложенные поля | общие ссылки | рекурсивная копия |

## Примеры (Go)

- **v1** - контракт `Clone()`, копия верхнего уровня не трогает шаблон
- **v2** - `[]Section` внутри: `cp := *r` мало (shallow), в `Clone()` нужен deep copy
