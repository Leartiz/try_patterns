# Factory Method

**Factory Method** - порождающий паттерн: базовый тип объявляет метод создания продукта, а **подкласс** (или другая реализация) решает, **какой именно** продукт вернуть.

Клиент работает с интерфейсом создателя и продукта, не зная конкретный тип.

## Схема

```
Client
  |
  v
Creator.Create()  ----->  Product
  ^
  |
PDFCreator / MarkdownCreator  (разные Create())
```

## Когда уместно

- тип продукта выбирается на этапе проектирования / конфигурации (формат, транспорт, парсер)
- нужно расширять набор продуктов новыми реализациями Creator, не меняя клиентский код

## Не путать

| | Factory Method | Simple Factory |
|---|----------------|----------------|
| Кто создает | подкласс Creator | одна функция / switch |
| Расширение | новый Creator | правка switch |

| | Factory Method | Abstract Factory |
|---|----------------|------------------|
| Сколько продуктов | один на Creator | семейство связанных |
