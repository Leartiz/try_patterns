# Sliding Window

**Sliding window** - техника для задач на подмассивы / подстроки: держим отрезок `[left, right]` и двигаем границы, не пересчитывая всё заново.

Идея: соседние окна почти одинаковы - добавить правый элемент, убрать левый. Часто вместо `O(n * k)` получается `O(n)`.

## Когда подходит

- ищем min / max / count по **непрерывному** отрезку
- ответ зависит от текущего окна, а не от произвольных индексов
- при сдвиге окна состояние обновляется за `O(1)` или `O(log n)`

## Два вида

| Вид | Границы | Пример |
|-----|---------|--------|
| fixed | длина окна постоянна | max сумма подмассива длины `k` |
| variable | `left` / `right` двигаются по условию | длиннейшая подстрока без повторов |

Типичный шаблон (fixed):

```
sum = сумма первых k элементов
для i от k до n-1:
    sum += a[i] - a[i-k]
    обновить ответ
```

## Не путать с

| | Sliding window | Two pointers |
|---|--------|-----|
| Фокус | содержимое окна | сходимость с концов / условие на паре |
| Часто | массив + агрегация | sorted array, palindrome |
