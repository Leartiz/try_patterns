# Euclidean Algorithm

**Алгоритм Евклида** находит НОД (GCD) двух чисел: наибольшее число, на которое оба делятся без остатка.

Идея: `gcd(a, b) = gcd(b, a % b)`. Остаток уменьшается, 
пока не станет `0` - тогда НОД = текущий делитель.

Пример: `gcd(48, 18)`

```
48 = 18 * 2 + 12
18 = 12 * 1 + 6
12 =  6 * 2 + 0   ->  gcd = 6
```

## Шаблон

```
пока b != 0:
    a, b = b, a % b
вернуть a
```

Сложность: `O(log min(a, b))`.

## Зачем

- сокращение дробей
- НОК: `lcm(a, b) = a / gcd(a, b) * b` (осторожно с переполнением)
- задачи, где нужна "общая кратность / шаг"
