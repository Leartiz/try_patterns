# Trie (prefix tree)

**Trie** - дерево, где путь от корня к узлу = **префикс** строки. 
Каждое ребро - один символ (или byte).

Не хранит строку целиком в узле: общий префикс у слов **разделяется** ветками.

Пример слов `cat`, `car`, `dog`. 
Читать сверху вниз: каждый уровень - одна буква. `*` - узел, где слово заканчивается.

```
              root
             /    \
            c      d
            |      |
            a      o
           / \     |
          t   r    g
          *   *    *
         cat car  dog
```

`cat` и `car` идут одним путем `c -> a`, на последней букве ветки расходятся (`t` vs `r`).
`dog` - отдельная ветка от корня, общих букв с `cat`/`car` нет.

Добавим `apple`: первая буква `a` - новый прямой ребенок корня (рядом с `c` и `d`). От root уже **3** узла.

```
                 root
              /   |   \
             c    d    a
             |    |    |
             a    o    p
            / \   |    |
           t   r  g    p
           *   *  *    |
                      l
                      |
                      e
                      *
                    apple
```

Если новое слово делит первую букву с уже существующей веткой (например `can`), от корня число детей не меняется - растет ветка ниже.

## Операции

| Операция | Идея |
|----------|------|
| Insert | идти по символам, создавать узлы, в конце пометить end |
| Search | идти по символам, в конце проверить end |
| StartsWith | идти по символам, достаточно дойти до последнего символа префикса |

## Когда полезно

- автодополнение, подсказки по префиксу
- словарь с общими началами слов
- IP routing (префиксы адресов)

## Trie vs hash map

| | Trie | map[string] |
|---|------|-------------|
| По префиксу | естественно | нужен перебор / другой индекс |
| Память | много узлов на короткие ветки | компактнее для разрозненных ключей |
